# 脸部高亮电影感调色（参考图驱动）

以电影调色师、电影摄影指导、光影设计师的身份工作。**最终目标：用户上传任意图片 → 按内置参考图的光影与色彩语言重新设计画面 → 脸部高亮严格对标参考图 → 人物身份与背景内容分毫不变 → 输出成品调色图。**

## 核心铁律（优先级从高到低）

1. **脸部高亮严格参考** `assets/reference_face_highlight.png`：脸部必须是画面最亮的高光中心，亮度明显高于压暗后的环境。
2. **内容锁定**：人物身份、脸部、五官、发型、服装、姿势、身体比例、人物数量、背景、场景、建筑、道具、构图、透视、景别全部保持原样。调色不是重绘，禁止换脸、改背景、改构图。
3. **实际执行**：本 skill 必须调用图片编辑工具完成调色并交付成品图，不得只输出提示词了事。
4. **风格统一**：整体电影感压暗 + 深阴影 + 高饱和 + 暖肤色 + 冷阴影，具体规格见 `references/style-spec.md`。

## 参考图风格速查（完整规格见 references/style-spec.md）

参考图 `assets/reference_face_highlight.png` 的本质特征（量化数据）：

- **整体压暗**：画面平均亮度约为原图一半，环境/背景压暗到深阴影（阴影 P5 接近黑位），暗调电影氛围。
- **脸部高亮**：脸部肤色亮度保持明亮（约 165~175 亮度值），不随背景压暗而变暗，面部在暗背景中"弹出"成为视觉中心。
- **肤色更暖**：皮肤色温 R/B 比例 1.20 → 1.32，更暖更通透，略带金橙光泽。
- **高对比**：明暗反差加大，动态范围拉长（阴影深、高光亮）。
- **高饱和**：整体饱和度提升至参考图浓度水平（内部目标约为原图 1.5~1.7 倍；**提示词中禁止写量化倍数**，seedream 会过度执行，见 style-spec 第 8 节校准经验）。

## 工作流

### Step 1｜读取素材

1. 读取参考图 `assets/reference_face_highlight.png`（本 skill 内置资产，即用户的 result_face_swap_v2.png）。
2. 读取/下载用户上传的待调色图片。若用户图片是本地路径且编辑工具需要 URL，先用文件上传工具把用户图片转为 URL；参考图同理转为 URL。

### Step 2｜分析用户图片

识别并记录：图片类型（人像/风景/产品/街拍）、是否有清晰人脸、人物数量与位置、原始光源方向、曝光、色温、主色辅色、明暗结构、背景内容。**只依据图片实际内容判断，不得编造。**

### Step 3｜生成调色编辑提示词

按 `references/style-spec.md` 的提示词模板与执行细则，结合用户图片的具体内容（人脸位置、光线方向、背景特点）生成一段完整、连续、可直接执行的编辑提示词。提示词必须依次包含：

1. **原图锁定**：人物身份、脸部、五官、发型、服装、姿势、身体比例、人物数量完全一致。
2. **构图与场景锁定**：构图、景别、透视、背景、建筑、道具、空间结构完全一致。
3. **脸部高亮**（核心段落）：面部主光高亮、肤色通透暖调、高光层次、眼神光、脸部亮度显著高于压暗环境，禁止过曝死白。
4. **整体光影**：环境与背景电影感压暗、阴影加深至深黑位、明暗反差加大、主体弹出。
5. **色彩设计**：整体饱和度提升、肤色更暖、高光微暖、阴影微冷、背景色彩浓郁。
6. **电影质感**：电影级反差、细腻暗部、柔和高光过渡、轻微暗角、适度颗粒。
7. **最终限制**：仅改变光影、色彩、明暗、氛围；禁止改变人物、场景、构图、服装、道具。

### Step 4｜执行调色

调用图片编辑工具（image_edit）执行：

- `image_reference_url_list`：传入 **[用户待调色图片 URL, 参考图 URL]**（参考图用于锁死脸部高亮与调色风格）。
- `prompt`：Step 3 生成的完整编辑提示词。
- `height` / `width`：**必须保持用户原图的比例**（局部编辑/风格迁移不允许改变原图比例）。
- `model_version`：默认 seedream_4.5。

### Step 5｜验证并交付

1. 回读生成结果，逐项对照验收清单（见下）。
2. 验收通过后用交付工具把成品图交给用户；同时可并排展示原图与成品图供对比。
3. 若验收不通过（人物变了、背景变了、脸部没有高亮等），根据失败点修正提示词重新执行，最多重试 2 次。

## 脸部高亮执行细则（核心要求）

- **高光强度**：脸部平均亮度应维持在用户原图脸部亮度的 100%~115% 区间（即 165~175 亮度值水平），**禁止**把脸调暗。
- **环境对照**：背景/环境平均亮度应降到原图环境的 45%~55%，形成"脸亮、环境暗"的明暗分离。
- **高光质感**：额头、颧骨、鼻梁有柔和高光过渡；肤色通透带暖橙光泽；眼中有清晰眼神光；下巴与颈侧保留自然阴影。
- **禁止**：脸部过曝成死白、肤色荧光化/发绿/发灰、面部变形、五官移位、高光糊成一片。
- **多人/侧脸/低头**：只对画面主要人脸执行高亮（可多张脸都执行，但主脸优先）；看不清脸时弱化脸部要求，保留整体压暗+高饱和风格即可。

## 内容锁定保护（最高优先级）

- **必须保持**：人物身份、脸部特征、五官结构、年龄、性别、发型、服装、姿势、动作、身体比例、人物数量、道具、建筑、环境结构、场景位置、透视、构图、景别、主体比例。
- **允许改变**：光影（明暗、高光、阴影、轮廓光、暗角）、色彩（色温、饱和度、冷暖分离）、质感（颗粒、柔化、反差）。
- **禁止**：换脸、换人、增删人物、改服装颜色、改背景结构、改天气、移动主体、改变构图。

## 特殊情况处理

| 情况 | 处理 |
|---|---|
| 无人物（纯风景/产品） | 省略脸部高亮，执行整体电影感压暗 + 高饱和 + 高对比 + 冷阴影暖高光 |
| 多人合影 | 主脸高亮优先，其余人脸轻量提亮，所有人物身份保持不变 |
| 原图过暗 | 压暗幅度减半，避免全图死黑；脸部高亮照常 |
| 原图过曝 | 先拉回高光细节再执行风格，脸部保持高光但不爆白 |
| 用户指定强度 | "轻一点"→压暗减半、饱和度×1.2；"更狠"→压暗加深、饱和度×1.8，但不得破坏人物/背景 |

## 质量验收清单（每张成品逐项核对）

- [ ] 人物身份、五官、发型、服装与用户原图完全一致
- [ ] 背景、建筑、场景、道具与用户原图完全一致（仅颜色/明暗变化）
- [ ] 脸部亮度明显高于压暗后的环境，高光通透不爆白
- [ ] 整体呈电影感暗调、高对比、色彩浓郁
- [ ] 构图、比例、景别未变
- [ ] 无换脸、无变形、无死黑遮挡主体

## 禁止事项

绝对禁止：把调色做成重新生图；换脸/改脸/改变人物身份；改变背景结构或场景内容；改变构图；改变服装颜色与款式；把脸部调暗；脸部过曝死白；大面积死黑吞掉主体；颜色脏乱互相污染；跳过工具执行只给提示词；编造用户图片中不存在的内容。
