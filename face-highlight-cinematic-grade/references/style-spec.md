# 参考图风格规格（style-spec）

本文件是 `face-highlight-cinematic-grade` 的风格执行依据。所有调色提示词必须以此为准生成。

## 1. 参考图识别

- 资产文件：`assets/reference_face_highlight.png`（即用户的 result_face_swap_v2.png，2730×1536）
- 画面内容：白绿配色汉服女子海畔廊亭自拍，前景人物 + 背景海面、船只、城市、棕榈叶
- 风格本质：**电影感暗调 + 脸部高亮 + 高饱和暖肤色**

## 3. 六大执行要点

1. **脸部高亮（第一优先）**：脸部是画面最亮中心，肤色亮度保持原图水平（165~175），高于压暗环境至少 30~50 亮度值。额头/颧骨/鼻梁柔和高光、眼神光清晰、下巴颈侧自然阴影。
2. **环境压暗**：背景与环境压暗至原图 45%~55%，阴影接近黑位但不死黑，保留暗部层次。
3. **高对比**：明暗反差加大、主体从背景弹出。
4. **暖肤色**：皮肤 R/B 比例向 1.3 靠拢，通透暖橙，禁止荧光/发绿/发灰。
5. **高饱和**：整体饱和度 ×1.5~1.7，背景色彩浓郁生动。
6. **冷暖分离**：高光微暖（R/B≈1.10）、阴影微冷，电影级色彩层次。

## 5. 不同图片类型的适配

- **人像/自拍/汉服写真**：完整执行脸部高亮 + 环境压暗，主脸优先。
- **多人合影**：主脸高亮优先，次要人脸轻量提亮，全部人物身份不变。
- **纯风景/无人物**：去掉脸部段落，保留整体压暗、高饱和、暖高光冷阴影、电影质感。
- **产品图**：产品为"主体"，用产品主体高光替代脸部高亮，背景压暗突出产品。
- **原图过暗**：压暗幅度减半（背景降至 65%~75%），避免死黑。
- **原图过曝**：先恢复高光细节，再执行风格；脸部保持高光但不爆白。

## 6. 强度分级

> 以下倍数是**内部验收目标**，写入编辑提示词时必须转成"以参考图浓度为限"的定性表述（见第 8 节校准经验），禁止直接写倍数。

- **轻（用户说"轻一点"）**：压暗至 65%~75%，饱和度 ×1.2，脸部高光保留。
- **标准（默认）**：压暗至 45%~55%，饱和度 ×1.5~1.7，脸部高光满格。
- **重（用户说"更狠/更电影"）**：压暗至 35%~45%，饱和度 ×1.8，阴影更深、暗角更明显；禁止死黑吞没主体。

## 7. 防幻觉与禁用

- 不得声称参考图来自真实胶片/导演/摄影机；只描述可执行的视觉结果。
- 不得编造用户图片中不存在的人物、场景、光源。
- 禁止在提示词中写"重新生成""换背景""换脸"等语义。
- 禁止输出参数表、LUT 数值、教程性内容；只输出一段可直接执行的编辑提示词。

## 8. 实测校准经验（seedream 图片编辑，2026-09 实测）

- **禁止在提示词里写"饱和度提升约X倍"这类量化倍数**：seedream 会严重过度执行（实测写"1.5倍"后全图饱和度冲到参考图的 2 倍左右）。正确写法是"饱和度提升至接近参考图浓度水平、以参考图浓度为限，宁欠勿过"。
- **脸部高亮写法**：写"面部亮度与压暗前的脸部持平""脸部亮度明显高于压暗后的环境"，实测能稳定得到脸部亮度 ~175-180、环境亮度 ~68 的明暗分离。
- **肤色控制**：写"肤色仅比原图微暖、禁止过橙"可把肤色 R/B 稳定在 1.28~1.32（参考图 1.32）。
- **验证口径**：全图平均饱和度会被深黑像素抬高失真（实测参考图全图 66.7、明亮区 59.7）。对比饱和度应只统计亮度在 70~220 区间的像素，目标与参考图明亮区饱和度差距在 ±10% 以内。
- **验收数据参考**（本次实测：原图 → 参考图 → 达标成品）：平均亮度 149 → 68 → 68；对比度 60 → 68 → 70；阴影 P5 42 → 4 → 1；肤色亮度 169 → 170 → 178；肤色 R/B 1.20 → 1.32 → 1.28。
